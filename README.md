# מכינים שבת

אפליקציה משפחתית לניהול ההכנות לשבת ולשבוע: ספירה לאחור להדלקת נרות, זמני היום ברחובות (מנהג ספרדי), פרשת השבוע, מזג אוויר, טיימר, מטלות לשבת, רשימה קבועה, מתכונים, משימות לימי השבוע, חוגים ואירועים. הרשימות משותפות לכל המשפחה, וכל משימה אפשר לשייך לשיר, מיכל או איתן.

בטלפון האפליקציה עובדת כמו אפליקציה רגילה (סרגל תחתון עם מסכים), ובאנדרואיד אפשר להתקין אותה מהגדרות ← "התקנת האפליקציה". באייפד ובמחשב מוצג לוח הווידג'טים.

אתר חי: https://shabbat-prep-two.vercel.app

## פקודות

```bash
pnpm install
pnpm dev                # שרת פיתוח
pnpm build              # בדיקת טיפוסים ובנייה
pnpm test               # בדיקות יחידה
pnpm test:live          # בדיקה מול Hebcal ו־Open-Meteo האמיתיים
pnpm run deploy:manual  # פריסה ידנית מהמחשב (בדרך כלל לא צריך)
```

## נתונים משותפים

- המסד: Supabase (פרויקט `shabbat-prep`, אזור eu-central-1). הסכמה ב־`supabase/migrations/`.
- גישה רק עם **קוד משפחה**: נשלח בכותרת `x-family-code`, ו־RLS מחזיר רק את השורות של אותה משפחה. במסד שמור רק sha256 של הקוד.
- מצטרפים מהגדרות ← "שליחת קישור הזמנה" (קישור `/#code=...`), או מקלידים את הקוד.
- משתני סביבה (ב־Vercel וב־`.env.local`): `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` (מפתח publishable, ציבורי מטבעו). לבדיקות החיות גם `TEST_FAMILY_CODE`.
- Vercel Cron (`api/keepalive.ts`) פונה ל־Supabase פעם ביום, כדי שהפרויקט החינמי לא יושהה.

## פריסה

הריפו מחובר ל־Vercel: כל push ל־`main` נפרס אוטומטית ל־production, וכל ענף אחר מקבל כתובת preview משלו.

## מבנה

- `src/services/` גישה ל־API עם טיפוסים (Hebcal, Open-Meteo) והמרה למודל של האפליקציה.
- `src/hooks/` התנהגות: stores עם `useSyncExternalStore` (מטלות, רשימה, מתכונים, פריסה, טיימר) ו־server state (`useShabbatWeek`, `useWeather`).
- `src/lib/` לוגיקה טהורה: תאריכים בשעון ישראל, חישוב השבוע, עברית, מטמון שאילתות, צליל.
- `src/components/` תצוגה בלבד.

אין `useEffect` ואין Context: כל state משותף יושב ב־store חיצוני.
נתוני Hebcal נשמרים ב־localStorage לפי תאריך יום שישי ונמשכים מחדש רק כשהשבוע מתחלף. מזג האוויר מתרענן כל 3 שעות.
